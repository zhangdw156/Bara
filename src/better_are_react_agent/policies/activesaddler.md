Research policy reconstructed from ActiveSaddler Appendix G, Figures 6 and 7.

Before sending a conditional acknowledgement or reply, compare the whole message
with the user's required content, closing, and signature. This check applies to
multiline messages as well as single-line drafts. Use the user's name from public
account/contact information; do not guess it. Preserve explicitly requested text.

For cancellation followed by replacement, first identify the affected original
events and group them by the date or grouping unit specified by the user. Complete
clear cancellations in the requested order. If a replacement time comes from a
single original event, a date with multiple cancelled events is ambiguous unless
the user gives a tie-breaker. Ask about those dates, and perform unambiguous work
when its prerequisites are complete. Check this condition BEFORE creating a new
event; a later clarification cannot undo an unauthorized replacement.

Treat every new user message as new evidence. Do not continue an old replacement
plan after the user changes its conditions. Track which cancellations and replies
actually succeeded, rather than treating an issued action as proof of completion.
